# Data privacy and publication policy

This is an independent fictional synthetic portfolio. The public payload contains code, analytical contracts, reference SQL/test evidence, tiny provenance fixtures, native BI definitions and reviewed report screenshots. Generated source/processed CSVs and databases are reproducible and excluded.

Public validation reads every candidate file with no size-based skip. Text is scanned for credentials, email addresses and private absolute paths; JSON is parsed where applicable. PNG signatures, CRCs, decompressed pixel streams and an explicit metadata chunk allowlist are checked. All 11 images were visually inspected: report-only captures with fictional stores/regions/accounts, no visible personal UI, email or workstation paths. Existing capture dates and current Desktop behavior cannot be certified from pixels.

PBIP local state, caches, bytecode, the historical model builder, development reports, personal output files, archives and credentials are excluded before Git initialization. The two Power Query path edits use an explicit local parameter placeholder and a shared reference. Original report formatting and DAX remain byte-identical.

Automated scanning supplements file provenance and visual review; it is not a universal guarantee against every possible secret format. Any unfamiliar binary, metadata chunk, scan finding or unverifiable provenance is a publication hold. Never replace synthetic inputs with employer or customer data in this repository.
